Company Employee Salary Analysis Using MySQL

📌 Project Overview

This project analyzes company employee salary data using MySQL. It explores employee salaries, departments, job roles, work experience, performance scores, and locations to generate meaningful business insights.

🎯 Project Objectives

- Analyze employee salary distribution.
- Identify the highest-paid and lowest-paid employees.
- Compare average salaries across departments.
- Analyze salary based on job role and experience.
- Evaluate employee performance scores.
- Compare salaries across different locations.
- Practice SQL queries for real-world data analysis.

🛠️ Tools Used

- MySQL
- MySQL Workbench
- SQL

📊 Database Details

Database name: "madh"

Table name: "company_employee_salary"

Columns

- "employee_id" – Unique employee identifier
- "employee_name" – Employee name
- "department" – Employee department
- "job_role" – Employee job position
- "experience_years" – Years of work experience
- "salary" – Employee salary
- "performance_score" – Employee performance rating
- "location" – Employee work location
